# FlashSell Business App

A premium full-stack data and airtime seller platform built with Node.js + Express and a modern responsive frontend.

## Features
- Premium landing page and dashboard
- Customer login/signup
- JWT-authenticated order APIs
- Data bundle and airtime shopping cart
- Checkout flow and order history
- Admin dashboard with sales summary
- Local JSON persistence for products/users/orders

## Default admin account
- Email: admin@flashsell.com
- Password: Admin@123

## Install and run
```bash
npm install
npm start
```

Then open:
```bash
http://localhost:5000
```

## Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express
- Auth: JWT + bcrypt
- Storage: JSON file (easy upgrade to MongoDB/Firebase)
